# Книга достижений — Дима и Кристина

Адаптивный статический сайт с пиксельной/Minecraft-атмосферой. Работает локально без сервера и может быть опубликован через GitHub Pages или Netlify.

## Запуск
Откройте `index.html` в браузере. Интернет для локального просмотра не нужен.

## Публикация
Загрузите содержимое этой папки в новый GitHub-репозиторий и включите Settings → Pages → Deploy from a branch → `main` / root. После публикации GitHub покажет адрес сайта.

## Файлы
- `index.html` — структура страницы
- `style.css` — адаптивный дизайн
- `script.js` — навигация, содержание, клавиши и свайпы
- `assets/` — обложка и 7 разворотов, оптимизированные в WebP

Содержание изображений сохранено; оригинальные PNG в проект не добавлялись, чтобы ZIP был легче.
